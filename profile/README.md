# NaNIsaac Research

Research code for X-ray diffraction and reflectivity: the questions, the numerical experiments that
test them, and the code, data and figures needed to reproduce the results.

## Current work

- [TraTT](https://github.com/NaNIsaac-Research/TraTT): time-dependent Takagi-Taupin simulation of
  how acoustic Bragg satellites form while a GHz sound wave enters a perfect crystal. The solver is
  on PyPI as `tratt`; the repository holds the analysis scripts, the lab notebook and the poster
  source.
- XRR inverse problem: how well a single X-ray reflectivity curve determines the parameters of a
  thin film. Work in progress, kept in
  [ReflectoLearn](https://github.com/NaNIsaac/ReflectoLearn/tree/research/identifiability/docs/identifiability).

## Presentations

- *Transient Formation Dynamics of Acoustic Bragg Satellites in Dynamical X-ray Diffraction.*
  Poster P2.17, KPS 2026 Fall Meeting, Jeju, 22 October 2026.

## Reproducibility

Each repository states how to rerun its results. Simulated data and figure scripts are kept in the
repository; measured data is included only where publication is permitted.
